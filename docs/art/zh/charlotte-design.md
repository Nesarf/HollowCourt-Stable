夏洛特是「空庭」中文声音（`Voice.heiress`）背后的人格 ✓。她是一个**新角色** ✓，只为一件事而生：**当应用说「这里还是空的。」时，说话的那个人是她** ✓。

## 二、owner 给出的外观三条（2026-09-26 ✓）

| | |
| --- | --- |
| **身材** | **傲人但不臃肿** ✓ |
| **礼服** | **优雅不俗套** ✓ |
| **私服** | **开放不妖娆** ✓ |

**这三条与上面那张区分表、以及下面「由此改了什么」，是同一层的东西** ✓ —— 都是**规范** ✓，不是形容 ✓。

**三个「不」不是修饰，是上界的划线** ✓✓ —— 这一族设定最容易画歪的地方恰好在同三个方向上：**大 → 臃肿** ✓、**华丽 → 俗套** ✓、**暴露 → 妖娆** ✓。所以 owner 写下的是**边界** ✓，而边界正是**没有立绘也可以先立住**的东西 ✓✓。

**为什么它重要** ✓：**外观这条线已经停了** ✓，她目前**没有立绘** ✓ → 这三行是**将来任何一次重新动笔的准绳** ✓✓（无论谁画 ✓、用什么工具 ✓），而它们**出自 owner 本人** ✓，比任何转述都硬 ✓。

### 衣着与更细的部分（owner 2026-09-26 补充 ✓）

**茶会鞋是两套都爱的，只是两副样子** ✓✓：礼服配的那双华丽 ✓，私服配的那双**更简洁、跟也更低** ✓ —— **同一双鞋的两个语域** ✓✓。这其实是**她整个结构的一个缩影** ✓：外出的场合层层讲究 ✓，日常的场合收起一半 ✓，而**偏爱始终是同一种** ✓✓。

**蕾丝与吊带袜是她一贯的偏好** ✓✓ —— 而这里要点明一件事 ✗：它们是**衣着材质**，**不是第四件道具** ✓✓。上面「道具只留三个」那条规矩**依然成立** ✓（缎带 ✓ 折扇 ✓ 石榴石 ✓）—— 蕾丝属于**面料层** ✓，不属于**随身物** ✓。

**她用小心的面料替代专门的一层 bra** ✓✓ —— 这是一条**材质优先**的规矩 ✓，而它在画面上读出来的是**垂坠与质感** ✓，不是裸露 ✓✓。这一条与上面「**私服开放不妖娆**」是同一句话的两种说法 ✓✓ —— **不妖娆**靠的正是**用面料解决**，而不是靠遮掩 ✓。

**裸睡派** ✓✓ —— 这一条**只属于人物卡与将来的插画** ✓✓，**不进应用的任何文案** ✗（应用里没有任何地方需要它 ✓）。

而它之所以是一条**性格设定**而不只是私事 ✓✓：她**在外层层设防**（本小姐 ✓ 哼 ✓ 才不是 ✓），**在家一点不留** ✓✓ —— **这是同一个人的两端，不是两套设定** ✓✓。写在这里，是因为将来任何一次画她或写她的人，都该知道这两端属于同一个人 ✓。

## 三、参考模型教会了什么，以及没教会什么

`E:\ANMS` 里有 owner 指出的**十一套角色包**，作为审美参考 ✓。其中两套用 `tools/blender_thumb.py` 渲染过并**实际看过** ✓。

**它们是 T-pose 的 3D 资产，不是成品插画** ✓ —— 因此可学的只是**比例、配色与细节节制** ✓，**不是线质** ✗，更**不是可以照抄的素材** ✗✓。

两套包**各自独立地**都做了同样五件事 ✓：

- **一个饱和的强调色，落在黑白底上** ✓ —— 两套都是红色 ✓；强调色**最多出现在三处** ✓，别处不出现 ✓；
- **剪影由外套承担** ✓ —— 燕尾服 ✓、带分离袖的长外套 ✓ —— 而不是往身体上加细节 ✓；
- **两三个小道具，为角色而不是为装饰** ✓ —— 一朵玫瑰 ✓ 红色发夹 ✓ 十字母题 ✓ 肩带 ✓；
- **头小、肩窄、腿长** ✓ —— 在胸像里等价于**肩线窄、脖子露出来** ✓；
- **眼睛大而亮带高光，鼻子与嘴几乎不画** ✓ —— 这就是这一类型自己的**五官预算** ✓✓。

## 四、由此改了什么

- **她加了一件斗篷** ✓ —— 外奶油白 ✓ 内牛血红 ✓。「剪影靠外套」✓，而她**一直没有外套** ✗ —— **这是最大的一处改动** ✓✓。
- **金色退成一条细边** ✓ —— 强调色只保留牛血红一个 ✓；金色只作滚边存活 ✓，因为**两个饱和色就是多了一个** ✓。
- **道具只留三个，不再多** ✓：喉间的缎带 ✓ 折扇 ✓ 颈饰上的石榴石 ✓。
- **肩线比矢量草稿更窄、脖子更长** ✓ —— 草稿是方的 ✓，而参考不是 ✓。
- **设计的其余部分不变** ✓：配色 ✓ 双马尾 ✓ 螺旋尾 ✓ 环头编发 ✓ 六角星高光 ✓ 傲娇姿态 ✓ 全部保留 ✓。

## 五、傲娇是结构性的

**两个姿势本身就是这种语域** ✓ —— **抱臂** ✓、**叉腰** ✓；**两个表情是这一原型存在的理由** ✓：**别过头撇着嘴** ✓、**满脸通红** ✓。**一个只能靠「换个笑容」来表达傲娇的设计，是一个没有主见的设计** ✓✓。

    表情   calm / smile / smug / tsun / flushed / cross / startled / triumphant
