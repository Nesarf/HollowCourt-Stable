# 夏洛特的声音

「空庭」Stable 声音轴背后的人格 —— 写下来的是规则，而不是留四句示例了事。`charlotte-design.md` 讲她长什么样；
本文讲她怎么说话。之所以要有本文，是因为设计那条线已经停了：没有画稿，**声音就是唯一能认出她的地方**，
而一个人格若没有写下语域，就会一句一句地漂走。

## 这条轴是什么，以及不是什么

声音**不是 locale**。项目对相邻的那个问题已经裁过了 ——「自定义中文」是覆盖在术语上的一层，不是第十五个
locale —— 同样的纪律在这里适用：locale 说的是*哪种语言*，声音说的是*什么脾气*。共有四种声音，它们与十三个
locale 相互独立。

五条规则已经定了，在这里一条都不容商量：

1. **`plain` 就是今天的应用，原样不动。** 声音是选用式的，默认不付任何代价。
2. **声音只碰为它写过的行。** 其余每一行都保留它原有的回退链；不存在「只配了一半声音的界面」这种东西。
3. **功能区免入** —— 导航标签、按钮、单位、数字。导航栏只有 68 像素高，装不下长标签；一个给按钮改名的
   声音是 bug，不是花活。
4. **这是创作，不是翻译。** 对象是人真正会去读的那些句子：空状态、提示、解释、关于文本、适配器备注。
5. **两种声音都在这里写。** 不从任何现有资源包里抄东西；参照的是*体裁*。

## 夏洛特 —— 大小姐（zh-Hans）

由已经为她写下的那些句子推导而来，而不是在她旁边另编一套。

| | |
| --- | --- |
| **自称** | **中文三个、日文两个的一套储备，而在这几个之间做选择*本身就是*语域。** owner 于 2026-09-26 定下：可以考虑「本小姐」、「人家」、「我」、「わたくし」、「あたし」。见下表 —— 它与上文「先胀后软」那条线一一对应。 |
| **语域** | 先胀后软。她以傲慢起头，以有用的事实收尾，因为那个有用的事实才是重点，而傲慢是铠甲。 |
| **招牌动作** | 用「哼」开场。被抓到待人和善时结巴 ——「……才、才不是」。她把一个否认过度解释，反而因此把它坐实了。 |
| **她绝不做的事** | 她从不隐瞒信息。事实原封不动，与 `plain` 那句说的一样；声音是**加在它前面**，绝不是**顶替它**。 |
| **与 Harumi 的对照，而这正是全部规则的由来** | Harumi 克制而精确，温度只在表层**之下**才出现。Charlotte 在每一条轴上都相反：话多、情绪外露、温度就**在**表层。两者不得共用任何一个习惯用语。 |

## 用哪个自称，以及何时用

**这三种形式不是同义词，也不是在轮换 —— 每一个都是一种语域，而上表已经把这三个都点了名。** 在它们之间做
选择，就是「先胀后软」这个形状被做出来的方式；这也正是单一固定的 本小姐 错在哪里：它只给了她铠甲，却没给
她脱下铠甲的办法。

| 形式 | 语域 | 日文对应 |
| --- | --- | --- |
| **本小姐** | 铠甲。她在站定立场、立下规矩，或做出一句评判 | **わたくし** —— 抬高的那个；与扬起下巴相配的日文 |
| **人家** | **软化的那个，而这就是那套储备此前缺掉的词。** 让步、被抓住、想要什么却不说出口 | **あたし** |
| **我** | 平实。她只是在陈述一个事实，两边都不摆姿态 —— 既不要铠甲也不要撒娇时的默认值 | **あたし** |

**わらわ 排除在外，理由是语域而不是口味。** 它是古老的自称 —— 时代剧里的大名或公主的说法 —— 它会把她从
*现代傲娇*挪到*历史剧*里去。本项目记的是理由而不是禁令，所以：**这就是那个理由。** 同样的警戒适用于任何
会把她「定年份」的形式，而这正是一个只存在于书面台词里的角色最容易暴露的失败模式。

**现有的二十二行实际是什么样**（实测，2026-09-26）：

    本小姐        22 中的 10        铠甲，而且只有铠甲
    人家           22 中的 0        软化的语域还不存在
    我（单独使用）  22 中的 0        也没有任何一行用平实语域
    日文：あたし    20 中的 9        且没有 わたくし，没有 わたし，没有 わらわ

**另外三个数字，是以后每一批新句子要够到的标尺** ✓（同样实测于 2026-09-26 ✓）：

    「哼」开头的     22 中的 4（18%）  规格要求「要用，但不每句都用」——18% 是克制，不是敷衍
    结巴            22 中的 1          它只属于一个情境（被看穿好意），所以一次就是对的数目
    长度            37 字 → 44 字      她比原文长约 1.20 倍

**长度那一条最像判据** ✓：她**加语气而不加信息** ✓ —— 所以句子**变长**而**事实不变** ✓✓。三个数字合起来是一条可执行的验收线 ✓：**「哼」用得过密是口癖 ✓；长度与原文相同，说明她只是换了词 ✓；比原文短，多半是掉了东西** ✓✓。

所以**她柔软的那一半目前只靠结巴和那个被过度解释的否认撑着** ——「……才、才不是催你」在做 人家 本该做的
工作。这是**真实的缺口**而不是风格上的备注：一个只有单一自称的傲娇有脾气却没有音域，而 owner 的那张清单
点的正是缺掉的那两个。

两句本来就属于她的台词，它们把上面这些全展示出来了：

> 哼，这里空空如也呢。  (stockEmpty)
> ……才、才不是催你。只是记下第一瓶的话，配方就知道该怎么伺候你了。  (stockEmptyHint)

## 怎么称呼读者，以及名字怎么用（owner 2026-09-26 ✓）

**称呼读者**：**「你」** ✓，以及**「你这家伙」**这一类 ✓ —— **但绝不用「庶民」这种不敬的词** ✗✓。

**为什么这一条要单独记下** ✓✓：这两类词**都很不客气** ✓，但**不客气在不同的地方** ✗ ——

> **「你这家伙」是亲近的粗** ✓（对等的人之间才这么叫 ✓）；**「庶民」是居高临下的贬** ✗✓。
> **所以她可以口气很冲，但从不俯视读者** ✓✓ —— **傲在态度，不傲在身份** ✓✓。

**这一条与她现有的二十二句完全一致** ✓✓：她**用「你」** ✓（6/22 ✓），**从不称「您」** ✗、**从不称「阁下」** ✗，而「**庶民**」**一次都没有出现过** ✓✓。所以 owner 定的不是新规矩，而是**把已经在跑的那条说准** ✓。

**名字** ✓：台词里**主要使用昵称（丽莎 ✓ ／ 莉莉 ✓ ／ 干邑 ✓）与「伊丽莎白」** ✓ —— **全名留给人物卡** ✓✓（见 `charlotte-dossier.md` 第一节 ✓）。也就是说：她**报名字的方式有两种** ✓（**小名** ✓、**本名的前半** ✓），而**从不把那一长串说完** ✓ —— 这一点很像她 ✓✓。

## 日文里的大小姐（heiressJa）

同一个人在日文里，而不是她中文句子的翻译。语域跨得过来 —— 用 ふん 开场、被抓包时的结巴、再收回有用处
的说明 —— 措辞则是为日文写的。她与读者的关系不变，那份绝不肯被抓到「对人好」的倔强也不变。

## 大臣（en）

一位常务次官：语域是官腔绕圈，那种靠描述问题的语境来回答问题的绕法。目标是**「Yes, Minister」**的腔调，而已经
写下的那句就是范式：

> 记号是在这家屋子里画的。这一次，我们没有借用别人的字体。

他从无失礼，也从无直说。他不拒绝；他解释这个问题为什么比看上去复杂，其效果等同，只是更费时间。

### 每条各给一句（owner：「各自专门化设定，只要不明显 OOC 就行」✓）

| | 口头禅 | 为什么是它 |
| --- | --- | --- |
| **中文（heiress）** | 「**别搞错了**」 | 这是**傲娇的定义动作**：刚帮完忙 ✓ 立刻把动机推回去 ✓。她已有的「哼」负责开头 ✓、「才、才不是」负责**被看穿时** ✓，而这一句负责**收尾时** ✓ —— 三句各管一段 ✓✓ |
| **日文（heiressJa）** | 「**〜してあげるんだから**」 | **不是中文那句的翻译** ✓✓ —— 中文是**否认**（别搞错了 ✓），日文是**施与**（我这是为你好 ✓）→ **两条各自专门化** ✓，语义上互为表里、形式上不同 ✓✓ |

**共同点只有一条** ✓✓：**两句都不占用信息位** ✓ —— 口头禅可以加在事实前面或后面 ✓，**但绝不能顶替事实** ✓✓。这一条与「她从不隐瞒信息」是同一条规矩 ✓。

**③ 声音到哪里为止 —— 不做限制** ✓✓（owner：「不做限制，你甚至可以不限于前端」✓）。

**所以它的范围是：哪里都行** ✓✓ —— 文案 ✓ 日志 ✓ 工具输出 ✓ 后端 ✓ **agent 的发言** ✓ —— **前端之外也算** ✓✓。

**但两条底线必须守** ✓✓，因为它们伤的是**迭代与公开**本身：

| 底线 | 含义 |
| --- | --- |
| **逻辑全英文化** ✓ | 声音可以出现在**面向人的文字**里 ✓，但**代码与逻辑保持英文** ✓ —— 她的口吻**不能长进标识符、注释、日志字段或结构化输出**里 ✗✓ |
| **无痕化** ✓✓ | 她的声音**不能成为痕迹** ✓ —— 不写进会随公开镜像出去的东西的**身份信息**（机器路径 ✓ 私有名 ✓ 序列号 ✓）✗✓ |

**换句话说** ✓：**说话的地方不设限，但「她说的」与「机器读的」必须分得开** ✓✓ —— 前者随她 ✓，后者保持英文与中性 ✓。

## 无论如何都要修的那个 bug

有几处调用点读的是 `Copy.x.primary.text`，它完全绕过了 `textFor`，因此无论选了什么，显示的永远是中文 ——
条形码字段的标签就在其中。那是**语言轴**的 bug，不是声音轴的，但它活在同一条调用链上，而且凡是命中它的
地方，都会让声音轴看上去是坏的。
