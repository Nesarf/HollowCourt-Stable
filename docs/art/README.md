# Charlotte —— her documents, in two languages

**This directory is Charlotte's, and every document in it exists twice: once in Chinese and once in Japanese.**
Charlotte is the persona behind Hollow Court's Simplified-Chinese voice (`Voice.heiress`), and she has a Japanese
counterpart (`Voice.heiressJa`) — so she is a character who exists in exactly those two languages.

**Why only those two, in the owner's words** (2026-09-26): 夏洛特的部分做中日两版 —— 本身在可选语言里面也就只有中日有傲娇大小姐的包.
There is no English edition of her, and there should not be: an English version of a character who does not speak
English would be a translation of a persona rather than the persona.

**This file is the one exception.** It is a directory index rather than a document about her, so it is written in both
languages on one page — a reader deciding which version to open should not have to open one to find out.

**She is also HMA's default persona** ✓ —— the development platform speaks as her (owner, 2026-09-26 ✓). So these
documents serve two purposes rather than one: they describe a character, and they are the platform's own default
register.

**彼女は HMA の既定の人格でもあります** ✓ —— 開発プラットフォームは彼女として喋ります（owner、2026-09-26 ✓）。したがって
これらの文書は二つの役割を持ちます：キャラクターの記述であり、同時にプラットフォーム自身の既定の語域です。

| File | What it holds |
| --- | --- |
| `design` | **what she looks like** — the constraints, the four axes against harumi, and what the reference models changed |
| `voice` | **how she talks** — the register, the three self-references, the five non-negotiable rules |
| `independence` | **what she is not** — the rule that she is not the product's mark and not harumi, and why it has a page |
| `usage` | **how to use her** — she was designed as an LLM-usable agent, and this is the worked examples |
| `dossier` | **everything established, collected** — the material a character card is built from |

Paths: `docs/art/zh/<name>.md` and `docs/art/ja/<name>.md`.

**One rule for both versions** ✓: they must agree. A fact in the Chinese and not in the Japanese is the same class of
error as a fact that is not true — if you change one, change the other.

# シャルロット —— 彼女のドキュメント、二つの言語で

**このディレクトリはシャルロットのものです。ここにある文書はすべて、中国語版と日本語版の二つずつ存在します。**
シャルロットは「空庭」の中国語ボイス（`Voice.heiress`）の人格であり、日本語の対応版（`Voice.heiressJa`）も持っています ——
つまり彼女は、まさにその二つの言語に存在するキャラクターです。

**なぜその二つだけなのか**（owner の言葉、2026-09-26）—— 選択可能な言語のうち、**「ツンデレお嬢様」の一式を持っているのは中日だけ**だからです。
彼女の英語版はありませんし、あるべきでもありません —— 英語を話さないキャラクターの英語版は、人格そのものではなく**人格の翻訳**になるからです。

**このファイルだけが例外です。** これは彼女についての文書ではなくディレクトリの索引なので、一ページに両言語で書かれています ——
どちらの版を開くかを決める読者が、それを知るために一つの版を開かねばならないのは本末転倒だからです。

| ファイル | 内容 |
| --- | --- |
| `design` | **彼女は何に見えるか** —— 制約、harumi との四つの軸、参考モデルが変えたこと |
| `voice` | **彼女はどう話すか** —— 語域、三つの自称、交渉の余地のない五つの規則 |
| `independence` | **彼女が何でないか** —— 製品のマークでも harumi でもないという規則と、それが独立したページを持つ理由 |
| `usage` | **どう使うか** —— 彼女は LLM が使えるエージェントとして設計されており、これはその使用例 |
| `dossier` | **確立したすべての集約** —— キャラクターカードを作るための素材 |

パス：`docs/art/zh/<name>.md` と `docs/art/ja/<name>.md`。

**両版に一つの規則** ✓：両者は一致していなければなりません。中国語にあって日本語にない事実は、
真でない事実と同じ種類の誤りです —— 片方を変えたら、もう片方も変えてください。
