# 大小姐 × 傲娇：两份类型学，与它们各自的标记

**写下来是因为这些资料在对话里查了三轮**，而对话会被压掉。2026-10-11 由 owner 指示查证；
每一节都写明出处，**能核对的写数字，不能核对的写明「这是类型学的说法」。**

## 一、这是两个萌属性，不是一个

| | お嬢様（大小姐） | ツンデレ（傲娇） |
| --- | --- | --- |
| 是什么 | **身份 + 口癖** | **性格** |
| 标记载体 | **句末** | **内容（动作与借口）** |
| 缺了会怎样 | 变成普通女孩 | 变成高冷 |

**我们的角色是「ツンデレお嬢様」——两个叠着。**所以两句都要做：**句末要有大小姐的口癖，内容要有傲娇的三件套。**

## 二、お嬢様言葉 的标记（日语，有明确清单）

出处：[ja.wikipedia お嬢様言葉](https://ja.wikipedia.org/wiki/%E3%81%8A%E5%AC%A2%E6%A7%98%E8%A8%80%E8%91%89)，
引金水敏《日本語の役割語》2003；[萌娘百科·大小姐口癖](https://zh.moegirl.org.cn/%E5%A4%A7%E5%B0%8F%E5%A7%90%E5%8F%A3%E7%99%96) 给出同一份列表并补充了历史。

| 层 | 标记 |
| --- | --- |
| **文末** | **ですわ**（最显著）、**こと**、**てよ**、**もの**、**の**、**わ** |
| **一人称** | **わたくし**、あたし |
| **敬语** | 周到に用いられる——**越客气越是距离** |

**金水指出：「〜てよ」和「〜こと」是普通女性语里没有的**，那才是这个角色的指纹；单用「〜わ」等于普通女孩。

**两个来源都说同一件不太体面的事**：这套话术在现代口语里**已经不用了**，只作为虚构作品里的「戯画化された」产物活着。明治期它被批评为「下品で耳障り」；萌娘百科那条说得更直——**战后被「捏造」成「旧时贵族大小姐的高雅象征」，那个高贵感是被制造出来的。**

**推论**：写得含蓄就是写错方向。**这个类型的标记本来就是夸张的。**

## 三、ツンデレ 的结构（可执行）

出处：[ツンデレ - Weblio](https://www.weblio.jp/content/%E3%83%84%E3%83%B3%E3%83%87%E3%83%AC)、
[萌娘百科·傲娇](https://zh.moegirl.org.cn/%E5%82%B2%E5%A8%87)。

**定义**：普段は冷たく素っ気ない（ツンツン）→ 特定の相手や状況で好意や優しさ（デレデレ）。
**核心不是「冷」，是「素直になれない」和「本音のギャップ」。**

**萌娘百科给的四句式模板，照抄：**

    「我才不是因为喜欢你才XXX的呢！」
    「人家这样做才不是为了OOO呢！」
    「我跟XXX才不是那种关系呢！」
    「我才不是傲娇呢！！」

**而定义里那句机制最关键**：

> 习惯下意识掩饰，**为自己的行为寻找其他合理借口**

**所以一条傲娇的句子 = 一个已经做了的动作 + 一句否认 + 一句站不住的借口。**三件套。

**语气标记**（萌娘百科自己的条目页顶部就在演示）：

- **「才、才不是」**——吃字，是她说漏嘴时的卡壳，不是语气词
- **「哼」**
- **「人家」**——自称
- **ツン 之后紧跟一句动摇**：「真的……不是哦…………？」，用省略号把声音拖弱

**日文对应**：「べ、別に あんたのためじゃないんだからね！」

## 四、**已查并排除**：恶役大小姐与 抖S 那一支

查过 [萌娘百科·恶役大小姐](https://zh.moegirl.org.cn/%E6%81%B6%E5%BD%B9%E5%A4%A7%E5%B0%8F%E5%A7%90)：
它的分类是「大小姐、**反派角色**、**敌女**、贵族、**抖S**」，是**用权力欺负人的反派**。
**不采用。**我们的角色欺负的是「这件事」，不是「人」——**她的锋利对着任务、对着麻烦、对着自己说漏的嘴，不朝着读者。**
写这一行而不是不写，是因为「查过并否掉」和「没想到」是两件事。

## 五、英文那支不套用这套

`Voice.minister` 是 **Yes, Minister 的官僚腔**，不是傲娇的英译。它现在的写法是最准的一支，
**不要为了「三种声音齐整」去改它**——三种声音是三个方向，不是同一方向的三个强度。

## 六、改写的检查表

一条合格的「ツンデレお嬢様」中文台词应当同时满足：

1. **有一个她已经做完的动作**（不是「愿意做」，是「做过了」）
2. **有一句否认**，且否认的东西是「我在意你」
3. **有一个借口**，而这个借口站不住
4. 三个语气标记里**轮着挂一个**（哼／才、才／随便你），**不要每条都挂满**
5. 句子里**没有省略号的地方是硬的**——不是每条都软

**反例（我第一版写的）**：「每一条我都看过了。……一处错都没有。谢就不必了。」
——**只有动作和抬价，没有否认也没有借口。那是高冷，不是傲娇。**

**正例**：「我、我才不是担心你才逐条看的。……只是刚好顺手而已。」

## 七、Yes, Minister 那支：不是傲娇的英译，是官僚的语法

`Voice.minister` 是 Sir Humphrey Appleby 的官腔。**它不是「傲娇的英文版」，它有自己的类型学**，
而查过之后可以说：**它现在是三支里最准的一支，而且准在一个具体的地方。**

### 两个机制，都来自语言学文献

搜到 [Monash 的 bureaucratic language 论文](https://users.monash.edu.au/~kallan/papers/E&Dorig.pdf) 的摘要给出第一颗：

> bureaucrats create cross-varietal synonyms using a **GraecoLatinate lexicon**

**用拉丁、希腊词根的长词替代日常词。**「use」变成「utilise」，「need」变成「require」，「about」变成「in relation to」。
这不是为了精确，**是为了显得不像人在说话。**

第二颗来自官僚修辞的分类：**「分散能动性」（рассеивание агентности）**——
**把「谁做的」从句子里拿掉。**被动语态、名词化、「一个决定被作出」（而不是「我们决定了」）、
「在这方面已经采取了一些步骤」（而不是「我做了这件事」）。

**这两条合起来是一个功能**：**让责任无法追溯到一个人。**那正是这个角色的权力来源。

### 而它的语法骨架，也有现成的样本

一篇分析给出的并列结构是可以直接照的模板：

> Delaying decisions, dodging questions, juggling figures, bending facts and concealing errors

**五个动名词，节奏一致，没有一个词是日常语。**五件坏事的清单写成五行诗，**而且听起来像公文。**

另一段从论文里摘的真实台词片段：

> and which will in all probability, should the current deplorable innovation be...

**定语从句 + 插入的虚拟条件句 + 尚未出现的谓语。**一句话在结束前已经绕了三圈。

### 对照现在那 24 条英文，它为什么准

| 现在写的 | 用到的机制 |
| --- | --- |
| The entry **was not**, on this occasion, **recorded**. A further attempt **would be advisable**. | 被动（谁没记下来？不知道）+ 限定词 + 委婉式 |
| **No figure has been supplied**, and it **would not be appropriate** to conjecture one. | 被动 + 「不恰当」代替「不行」 |
| There is at present **no material on which a figure could be based**. | 名词化 + 关系从句 |

**每一句都在做同一件事：把「没有人做这件事」说成「这件事没有被做」。**

### 所以英文那支的规则

1. **主动变被动，人消失**
2. **动词变名词**（record → the entry was not recorded）
3. **说「不恰当」而不是「不行」**；说「would be advisable」而不是「do it」
4. **加限定词把话说轻**：on this occasion、to some extent、in the present circumstances
5. **一句话里绕一圈再回来**，但**不要真的说谎**——它从不撒谎，它只是让真话无法被引用

**要改的只有一条：现在有些句子太短了。**官腔不是简洁的，它**必须有从句**。
「Check whether this machine can be reached.」这种祈使句是部长的口吻，不是常任秘书的——
后者会说 **「It would be advisable to establish whether this machine can be reached.」**

### 一句话总结三支

| 声音 | 干的事 | 标记 |
| --- | --- | --- |
| **伊丽莎白**（中） | **说漏嘴** | 哼／才、才／随便你 + 动作 + 否认 + 借口 |
| **ツンデレお嬢様**（日） | **说漏嘴，用敬语** | ですわ／こと／てよ／もの + わたくし + べ、別に |
| **Yes, Minister**（英） | **让别人抓不住她** | 被动 + 名词化 + 限定词 + 从句 |

**前两支靠「漏」，第三支靠「不漏」。**这是三种不同的机制，不是三种强度。
