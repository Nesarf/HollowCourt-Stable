### 八之一、`CL` 的构建号是 `48000` ✓，而颜色住在显示名里 ✓✓（2026-09-29 定 ✓）

**owner 定了 `1.0.0.48000-J1407b-FFF8E7` 这个写法 ✓ —— 量过之后它通过全部约束 ✓✓：**

| 查什么 | 结果 |
| --- | --- |
| **不安全字符**（`#` ✓ `/` ✓ 空格 ✓ `%` ✓ `&` ✓ `+` ✓ `?` ✓） | **一个都没有 ✓✓ —— 所以它既能当显示名 ✓，也能当产物文件名 ✓** |
| **单调** | **`2184 → 2221 → 2880 → 3028 → 3640 → 3939 → 44100 → 48000` ✓** |
| **三份 APK 各自的 `versionCode`** | **`1000 × ABI 偏移 ＋ 48000`** ✓ —— **量过 2184 那一轮：`3184` ✓ `4184` ✓ `6184` ✓，三份各不相同 ✓** |

### 三层各放什么 ✓（以 Flutter 文档的原话为准 ✓）

| 层 | 放什么 | 约束 |
| --- | --- | --- |
| **`pubspec.yaml` 的 `+` 后面** ✓ | **`48000`** ✓ | **必须是**整数**** ✓ —— 文档：`--build-number`「On Android it is used as `versionCode`」✓ |
| **`versionName`（给人看的）** ✓✓ | **`1.0.0.48000-J1407b-FFF8E7`** ✓ | **自由字符串 ✓** —— 文档：`--build-name`「a string used as the version number **shown to user**」✓ |
| **产物文件名** ✓ | **从 `versionName` 来 ✓** | **不能含 `#`** ✗✓ —— **GitHub 的下载链接里 `#` 是片段分隔符 ✓，它后面的部分不会到达服务器 ✓✓** |

**⇒ 而那个偏移只活在 `versionCode` 里** ✓✓：**三个 ABI 拿到**三个不同的数**** ✓（这样每一份都能独立升级 ✓），**而 `versionName` 三份**完全一样**** ✓ —— **用的是 pubspec 里那个数**本身**** ✓。
**它由 Flutter 的 split-per-abi 加进去 ✓**（`build.gradle.kts` 自己的注释：「When using split APKs, `1000 * ABI_VERSION` is added automatically by Flutter」✓✓），**不是这个工程的约定 ✗** —— 先前这里写成「2000 ＋ 构建号」是错的 ✗✓。

**⇒ 所以规矩是一句话** ✓✓：**版本**号**必须是整数 ✓（安装器只认它 ✓），版本**名**是自由字符串 ✓ ——
**而在这个工程里它还会变成文件名 ✓，所以只能用文件名安全的那批字符 ✓✓：字母 ✓ 数字 ✓ `.` ✓ `-` ✓ `_` ✓。**
**`#` 是唯一一个真正过不去的 ✗** ✓ —— **所以 `FFF8E7` 要写就写这三个字节本身 ✓，不带井号 ✓✓。**

**而 `1SWASP J140747.93−394542.6` 是发现 J1407b 的那颗恒星 ✓** —— **那颗带巨大环系的系外行星 ✓ ——
与「宇宙拿铁」这个来自**全宇宙平均色**的名字是同一路的 ✓✓。**

**而 `#39C5BB` 用同一种压法会得到 `0x39C5BB` = `3786171`** ✓ —— **但 3939 是 owner 明确给的号 ✓，所以那一步不动它 ✓；如果到那一步想换成颜色号，这个数在这里 ✓。**
